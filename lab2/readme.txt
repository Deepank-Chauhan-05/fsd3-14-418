# File System (fs) of Node.js
It allows JavaScript code to run outside the browser and interact directly with the operating system.

# Common operations on files/folders

- Reading and writing files
  => readFile(), writeFile(), appendFile()

- Directory management
  => mkdir(), readdir(), rmdir()

- Watching for changes
  => watch(), watchFile(), unwatchFile()

- Streaming large files
  => createReadStream(), createWriteStream()

- File operations
  => rename(), copyFile(), unlink(), stat(), existsSync(), access()
